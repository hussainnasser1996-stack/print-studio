# Example outputs

PDFs and HTML built using this skill. Useful for:

- Comparing aesthetic directions side by side
- Showing the user what each direction produces before they pick
- Providing concrete reference for future builds (style continuity for the same client/firm)

## Convention

```
examples/
├── <yyyy-mm-dd>-<company>-<doc-type>-<direction>/
│   ├── teaser.html
│   ├── <Company> – <Doc Name>.pdf
│   ├── README.md       (sources, version notes, regenerate command)
│   └── assets/         (any non-base64 working assets)
```

Older examples accumulate over time. Don't delete them — they're the easiest way to maintain visual continuity if a follow-up doc needs to match an earlier one.
